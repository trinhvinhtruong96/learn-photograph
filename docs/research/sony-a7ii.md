# Sony α7 II (ILCE-7M2) — verified facts

## Sources
- **HG** = official Help Guide, ILCE-7M2 (web: https://helpguide.sony.net/ilc/1450/v1/en/index.html ; full PDF: https://helpguide.sony.net/ilc/1450/v1/en/print.pdf). Topic numbers like [84] are the Help Guide's own. It covers firmware up to 4.00: it describes "Focus Standard" (added in 4.00) and "RAW File Type" (added in 2.00).
- **SPEC-IN** = Sony India spec page (the most complete one): https://www.sony.co.in/electronics/support/e-mount-body-ilce7-series/ilce-7m2/specifications
- **SPEC-US** = https://www.sony.com/electronics/support/e-mount-body-ilce-7-series/ilce-7m2/specifications (opened in a headless browser because plain HTTP requests got 403).
- **FW** = Sony firmware history (official, in Japanese): https://support.d-imaging.sony.co.jp/www/cscs/firm/?area=gb&lang=en&mdl=ILCE-7M2
- UI notation as Sony writes it: `MENU → (Camera Settings) → [Item]`. "(Camera Settings)" is the camera-icon tab and "(Custom Settings)" is the gear-icon tab. Sony only shows these tabs as icons. The names in brackets are the names Sony uses for them.

## Other α7 II quirks a beginner should know
- **Lens Compensation** (`MENU → (Custom Settings) → [Lens Comp.]`): [Shading Comp.] defaults to Auto, [Chro. Aber. Comp.] to Auto, [Distortion Comp.] to Off. Only works "when an E-mount lens is mounted". These corrections affect JPEGs and the preview. RAW editors apply their own (darktable: lens correction module) [INFERENCE about RAW]. (HG [163]–[165])
- **[Release w/o Lens]** defaults to Enable, so the camera fires with no lens or with a lens that has no contacts. Metering may be wrong with such lenses. (HG [159])
- **[Live View Display]**: with "Setting Effect ON" (default) the screen shows the effect of exposure compensation and white balance. If the screen looks wrong in M mode with flash, check this setting. (HG [157])
- **Memory recall 1/2** on the mode dial saves complete setups, e.g. 1 = portrait, 2 = night. Use `MENU → (Camera Settings) → [Memory]`. Slots M1–M4 need a memory card. (HG [44], cover page "Memory")
- **Battery life is short** (270 shots with the viewfinder). The camera charges over Micro USB.
- **Movies are limited to ±2 EV** compensation and ISO 200+.
- **Firmware**: update to **Ver. 4.01**. Uncompressed RAW needs 2.00 or later. "Focus Standard" AF-point moving needs 4.00 or later. (FW)
- **ISO AUTO range** is 100–6400 by default. Raise [ISO AUTO Maximum] for night work. (SPEC-IN, HG [108])
- **Multi Frame NR** (in the [ISO] menu) stacks frames into a JPEG with less noise. It is JPEG only [INFERENCE: HG says it combines images into one; RAW not mentioned].
- **Dials per mode** (HG PDF, Aperture Priority / Shutter Priority / Manual Exposure pages): **A**: "Select the desired value by turning the front/rear dial." **S**: the same wording, for shutter speed. **M**: "Select the desired aperture value by turning the front dial. Select the desired shutter speed by turning the rear dial." [Dial Setup] (`MENU → (Custom Settings) → [Dial Setup]`) swaps the two dials and only applies in M. Default: front = F/no., rear = SS. In M with [ISO AUTO], the ISO value blinks when no ISO gives a correct exposure. Shutter speeds of 1 s or longer trigger noise reduction that takes as long as the exposure. (https://helpguide.sony.net/ilc/1450/v1/en/print.pdf ; https://helpguide.sony.net/ilc/1450/v1/en/contents/TP0000226610.html)

## Spec corrections summary
1. Stage 2 §3: remove "Expand Flexible Spot". It does not exist on the α7 II.
2. Stage 5 portrait settings: change "AF-C + Eye AF" to "AF-S + Eye AF (assigned button, hold it)". Sony says Eye AF may not work in AF-C.
3. §11: there is no ISO AUTO minimum shutter speed. Teach M + ISO AUTO or S mode instead.
4. The file-format setting is named [Quality]. RAW compression is [RAW File Type] (firmware 2.00+).
5. Add the ranges: EC dial ±3 / menu ±5. WB 2500–9900 K. Bracket 3/5 frames up to 3.0 EV. 5 fps. Sync 1/250. Battery 270/350.
