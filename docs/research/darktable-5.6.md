# darktable 5.6 fact check (for spec 2026-10-22-photography-roadmap-design.md)

Sources: darktable 5.6 user manual (docs.darktable.org/usermanual/5.6/en/), release notes on darktable.org and GitHub (release-5.2.0 / 5.4.0 / 5.6.2 tags), darktable source code at tag release-5.6.2, rawspeed `cameras.xml`.
Manual convention: module names are lowercase and italic in the manual (e.g. *color balance rgb*). The app should use the same spelling.

## A. Verified beginner workflow (ordered, exact module names)

The manual's "process" page ([link](https://docs.darktable.org/usermanual/5.6/en/overview/workflow/process/)) says: do the basics first ("image processing in 3 modules"), then *corrections*, then *creative adjustments*. It also says to enable *lens correction* **before** setting exposure, because vignetting correction changes overall brightness. Here is that order, adapted to the 5.6 default tone mapper (*sigmoid*):

0. Setup (once): preferences (gear icon) > processing > **auto-apply pixel workflow defaults**. The default is "scene-referred (sigmoid)", so leave it. In the module-group menu (hamburger icon) pick the preset **"workflow: scene-referred"**. If you reopen an image, first click the *reset* button in *history stack* ("discard history").
1. **lens correction**: just turn it on. It auto-detects the lens and applies all corrections.
2. **exposure**: drag the *exposure* slider to set overall brightness (mid-gray). Turn on **color assessment mode** with **Ctrl+B** while doing this.
3. **sigmoid** (default) / **filmic rgb** / **AgX**: tone mapping, which sets contrast and white/black handling. (The manual walks through this step with *filmic rgb*: *scene* tab white/black relative exposure, then *look* tab *contrast*.)
4. **color balance rgb**: saturation. Start from the **"basic colorfulness"** preset.
5. Corrections:
   - **color calibration**: white balance, in the CAT tab. Leave *white balance* on "camera reference".
   - **denoise (profiled)**
   - sharpening and local contrast with **local contrast** / **diffuse or sharpen** / **contrast equalizer**
   - **highlight reconstruction**
   - **rotate and perspective**: to level the horizon, right-click and drag along it.
   - **retouch**
   - **haze removal**
6. Creative adjustments:
   - **crop** / **framing**
   - dodge and burn: an extra *exposure* instance with a drawn mask, or **tone equalizer**
   - monochrome: **color calibration** *gray* tab
   - color grading: **color balance rgb**

**Spec §3 Stage 5 lesson 3 is WRONG in its order** ("crop & straighten → exposure → WB → tone mapper → contrast → color → noise & sharpening → lens correction").
- The manual puts lens correction **first** (before exposure).
- It puts crop/rotate under *creative adjustments*, after corrections.
- WB in color calibration is a correction step. The manual assumes camera WB first and fixes it "if not correct".

Suggested replacement: **lens correction → exposure → tone mapper (sigmoid) → color calibration (WB, if needed) → color balance rgb → denoise (profiled) / local contrast (or diffuse or sharpen) → rotate and perspective & crop → retouch/masks**.
Note: module order in the pixelpipe is fixed, so the order you edit in does not change the result. This list is about the order you *work* in.

## C. Other spec wording to fix
- §3 Stage 6.4: replace "wheels" with "*4 ways* tab (shadows lift / highlights gain / power)". Teach "basic colorfulness" + *global vibrance* first.
- §3 Stage 6.5: "styles (presets)" → "styles (saved multi-module edits; created in the *styles* module or the darkroom *history stack*)".
- §3 Stage 5.2: "compare view" → "culling mode (X / Ctrl+X)"; inspect with W / Ctrl+W.
- §11: tone mapper = sigmoid (default since 5.2). Warn that the manual's own getting-started page still uses filmic rgb.
- The 5.6.1 release post says the "documentation is not currently complete for release 5.6" (https://www.darktable.org/2026/08/darktable-5.6.1-released). This explains the filmic leftovers.

- Exact *sigmoid* control names were not fetched (the manual's 3-module walkthrough describes filmic rgb only).
- HSL-style module names (*color equalizer*, *color zones*) were not checked.
- The module-group preset name "workflow: scene-referred" is taken from the 5.6 process page as-is.
