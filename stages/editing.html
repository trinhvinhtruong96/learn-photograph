RAW files keep everything

In one sentence

A RAW file keeps all the light data, and darktable never changes it.

A RAW file holds everything the sensor recorded. It looks flat at first because nothing has been processed yet.

Your original file never changes in darktable. The app saves your edits in a small sidecar file next to it, such as DSC01234.ARW.xmp.

Back up the sidecar files together with the RAW files. Without them, your edits are gone.

Picture it

Think of a recipe card stored next to raw ingredients. The ingredients stay untouched. The card says how to cook them.

Example

You edit a sunset photo in three different ways. The RAW file stays the same, and you can go back to the original at any time.

In darktable

Edits save automatically to the .xmp file. You never press a save button for edits.

Try it now

Open one RAW file in darktable, change the exposure, and close it. Find the .xmp file next to the RAW in your folder.

Organize and cull

In one sentence

Put photos in dated folders, then keep only the best ones.

Copy each shoot into a folder named by date and event, such as 2026/2026-10-25_market. Then add the folder to darktable.

Culling means picking the best photos and rejecting the rest. First reject the clear misses. Then give stars to the ones you like.

Picture it

Think of picking fruit at a market. First you drop the bruised ones. Then you choose the best of the rest.

Example

From 200 photos of a market, you reject 120 blurry or dull frames. You give 3 stars to 10 of the rest. Those 10 are your edit.

In darktable

In the lighttable, use import › add to library. Hover over a thumbnail and press 0 to 5 for stars and R to reject. F1 to F5 add color labels.

Culling mode is X (fixed) or Ctrl+X (dynamic). Hold W for a full preview.

Try it now

Import your last shoot. Reject the misses with R, then star your top 10.

Set up darktable once

In one sentence

Check one setting so darktable starts every RAW file the modern way.

darktable 5.6 starts each RAW file with a few modules already on. The setting that controls this is called the pixel workflow.

Keep the default: "scene-referred (sigmoid)". The darktable manual's getting-started page still shows an older module called filmic rgb. This course uses sigmoid.

Picture it

Think of setting up a new kitchen once. After that, every meal starts from the same tidy counter.

Example

You open a RAW file and it already looks brighter and has contrast. That is the default workflow doing its job.

In darktable

Open preferences, then processing. Check that auto-apply pixel workflow defaults is set to "scene-referred (sigmoid)".

The basic edit, in order

In one sentence

Work through the same nine modules, in the same order, on every photo.

A fixed order keeps you from going in circles. The order inside darktable is fixed anyway. This list is the order you work in.

  1. lens correction: turn it on first. Fixing dark corners changes the brightness.
  2. exposure: set the overall brightness. The module already adds +0.7 EV, like a camera JPEG. Press Ctrl+B for color assessment mode while you judge it.
  3. sigmoid: sets the contrast and keeps the brightest and darkest parts under control.
  4. color calibration: fixes white balance, if needed.
  5. color balance rgb: start from the preset basic colorfulness, then adjust global vibrance.
  6. denoise (profiled): removes noise with a profile made for the α7 II.
  7. local contrast or diffuse or sharpen: brings back crisp detail.
  8. rotate and perspective and crop: straighten the horizon and trim the edges.
  9. retouch: removes dust spots and small distractions.
Picture it

Think of getting dressed. Socks go on before shoes. Lens correction goes on before exposure for the same reason: each step depends on the one before.

Example

An underexposed sunset street. Lens correction lifts the dark corners, and exposure +1 EV brings back the street. Sigmoid adds punch.

Color calibration warms the light a little, and color balance rgb adds color. Denoise cleans the sky, local contrast adds crispness, and a small rotation fixes the tilted horizon.

In darktable

Open a photo in the darkroom and work down the list from step 1 to step 9. Skip a step only when the photo does not need it.

Try it now

Edit one photo using all nine steps in order. Take note of which step changed it most.

Compare before and after

In one sentence

A snapshot lets you compare your edit with an earlier version.

After a while, your eyes get used to an edit. A side-by-side comparison shows if it really looks better.

A snapshot saves the current look. The history stack lists every edit in order, so you can step back.

Picture it

Think of a before and after photo in a magazine. Side by side, the change is obvious.

Example

You push the colors hard. In a split view next to the snapshot, the skin looks orange. You pull color balance rgb back a little.

In darktable

In the snapshots module, click take snapshot. Then click the snapshot for a split view. Click an older item in the history stack to see that step.

Edit a whole set

In one sentence

Copy the edit from one photo and paste it onto the others.

Photos from one shoot often share the same light. Edit one, then copy its edits to the rest.

Plain copy skips white balance and lens correction, because those can differ per photo. Selective copy lets you choose exactly which modules to paste.

Picture it

Think of a stamp. Carve it once, then press it on every page.

Example

Ten photos from one market at dusk: edit the best one, copy it, and paste onto the other nine. Then fine-tune exposure on each.

In darktable

Use Ctrl+C and Ctrl+V to copy and paste all edits. Use Ctrl+Shift+C and Ctrl+Shift+V to pick modules.

Export for web and print

In one sentence

Export makes a finished JPEG and leaves your RAW untouched.

The web needs small files in the sRGB color space. Print needs the full size.

A web size of 2048 pixels on the long side looks sharp on phones and laptops. Quality 90 keeps files small with no visible loss.

Picture it

Think of printing a document as a PDF. The original stays editable. The PDF is the copy you share.

Example

You share 10 travel photos online: JPEG, sRGB, quality 90, 2048 pixels. For a big print, you export the same photos at full size.

In darktable

In the export module: file format JPEG, quality 90, set size in pixels with max size 2048 × 2048, profile sRGB. For full size, set max size to 0 × 0.

Back up with the 3-2-1 rule

In one sentence

Keep 3 copies of your photos, on 2 kinds of storage, with 1 copy somewhere else.

Drives fail and laptops get stolen. A backup plan protects years of work.

The 3-2-1 rule: 3 copies, on 2 kinds of storage, with 1 copy off-site. Include the .xmp sidecar files.

Picture it

Think of spare house keys. You keep one in your pocket, one at home and one with a friend.

Example

Your photos live on the laptop, on an external drive, and in a cloud folder. If the laptop dies, you lose nothing.

In darktable

Back up the whole photo folder, not only darktable. The library and the .xmp files hold your edits.

Practice

Common mistakes

  • Thinking JPEG is better because RAW looks flat.

    RAW is unprocessed. Editing gives it life and keeps all the data.

  • Worrying that editing changes the original.

    darktable keeps edits in the .xmp sidecar.

  • Expecting RAW to rescue a pure white sky.

    Fully white areas hold no detail. Protect highlights when you shoot.

  • Sharpening to fix missed focus.

    Sharpening cannot create detail that was never captured.

  • Exporting Adobe RGB for the web.

    Use sRGB for screens and the web.

Self-check

Which module do you turn on first, and why?

lens correction, because fixing dark corners changes the brightness.

What does Ctrl+Shift+V do?

It pastes only the modules you choose.

Where are your edits stored?

In the .xmp sidecar next to the RAW file.

Which export settings suit the web?

JPEG, sRGB, quality 90, max size 2048 × 2048.

Your camera was on Daylight under orange lamps. Can you still fix it?

Yes. Set white balance in color calibration, because the RAW file keeps the data.
